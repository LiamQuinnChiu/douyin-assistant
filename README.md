# 抖音助手

一个带图形界面的抖音私信自动回复机器人：通过浏览器自动化控制抖音网页版私信页面
(www.douyin.com)，接入 OpenAI 兼容接口的大模型（默认 DeepSeek）实现自动回复。

> ⚠️ **风险提示**：自动化操作抖音违反平台规范，存在**限流/封号风险**。
> 请务必用小号测试、控制回复频率（默认每会话最小间隔 2 秒）、不要用于营销/骚扰。
> 使用本项目即表示你已知悉并自行承担风险。

## 功能特性

- 🖥️ PySide6 桌面 GUI，暗色主题 + 抖音红配色
- 🎵 抖音图标、标题「抖音助手」
- 🤖 Playwright 控制浏览器，扫码登录一次后持久化
- 🧠 接入任意 OpenAI 兼容模型（DeepSeek / OpenAI / 通义等）
- ✅ 会话白名单、上下文记忆、回复频率限制、关键词黑名单
- ✉️ 手动发送消息、一键测试模型连接

## 原理

- 用 Playwright 控制系统 Edge/Chrome，打开抖音网页版私信页（https://www.douyin.com/chat?isPopup=1）
- 扫码登录一次后，登录态持久化到 .douyin_profile 目录，之后免扫码
- 通过 DOM 读取当前会话消息，操作 Slate 编辑器输入 + 点发送按钮回复

## 环境要求

- Windows 10/11
- 系统装有 Edge 或 Chrome（Windows 自带 Edge）
- 手机抖音 App（首次扫码登录用）
- 项目已内置 Python 3.12（.python312/），无需另装

## 快速开始

1. 双击 start.bat（或运行 .python312\python.exe main.py）。
2. 首次会弹出浏览器打开抖音私信页，**用手机抖音 App 扫码登录**。
3. 右侧「模型设置」填接口地址 / API Key / 模型名（DeepSeek 默认：
   接口 https://api.deepseek.com/v1 ，模型 deepseek-chat）。
4. 点「测试模型连接」确认可用。
5. 点「连接」，浏览器会打开私信页并自动点开第一个会话。
6. 「刷新会话」→ 勾选要自动回复的会话 → 打开「开启自动回复」。

## 配置

所有设置均可在 GUI 内修改，自动保存到 config.json。

| 配置项 | 说明 |
|--------|------|
| 接口地址 / API Key / 模型名 | 大模型接入信息 |
| 温度 / 最大输出 / 超时 | 模型参数 |
| 开启自动回复 | 总开关，默认**关闭** |
| 回复最小间隔 | 同一会话两次回复的间隔（秒） |
| 上下文记忆轮数 | 每个会话保留的对话轮数 |
| 黑名单关键词 | 逗号分隔，命中则不回复 |
| 人设提示词 | 机器人的人格与回复风格 |

## 常见问题

**Q：连接后提示「未登录，请扫码」？**
在弹出的浏览器里用手机抖音扫码登录，登录成功后自动开始工作。

**Q：读不到消息 / 不自动回复？**
检查：① 浏览器里已点开目标私信会话；② 「开启自动回复」已打开；
③ 左侧已勾选该会话；④ 消息是文本。

**Q：发送失败或没发出去？**
抖音网页版 DOM 会不定期改版，若失效需调整 douyin_adapter.py 里的选择器。
